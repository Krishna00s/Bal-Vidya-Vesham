# Bal Vidyavasham --- Design Documentation

This folder contains the foundational design documentation for the Bal
Vidyavasham school website.

-   [ARCHITECTURE.md](ARCHITECTURE.md) --- application, page, content,
    responsive, accessibility, and motion architecture.
-   [LAYOUT.md](LAYOUT.md) --- homepage composition and the 01--10
    editorial section layout.
-   [SYSTEM.md](SYSTEM.md) --- colors, grid, spacing, surfaces, imagery,
    buttons, motion, and component rules.
-   [TYPOGRAPHY.md](TYPOGRAPHY.md) --- Swiss-inspired typographic
    hierarchy and responsive type rules.

The system is based on the supplied homepage mockup and the previously
established project direction: Swiss-inspired editorial design, strict
grid alignment, restrained visual language, strong school photography,
and purposeful motion.
